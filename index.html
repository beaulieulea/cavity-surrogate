Lid-driven cavity: neural-network surrogate vs CFD

Student:

Evaluates the exported MLP (inputs x, y, Re) at all 50 × 50 cell centres in your browser. No CFD is run and nothing is trained here.

What this shows. The network was trained only on CFD cases with Re = 20 to 300 and is not retrained here. For Re above 300 it is asked to extrapolate. The CFD reference for each Re was computed offline by a separate finite-difference solver (streamfunction-vorticity, 200 x 200 grid) and is used only to check the prediction, never for training. Both panels show the same quantity, at the same Re, on one common colour scale. Reading the differences: they combine extrapolation error with a baseline gap, because this reference solver is finer than the one that generated the training data (visible already at Re = 300, inside the training range; pressure near the lid corners is singular and differs most).
